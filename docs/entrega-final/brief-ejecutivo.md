# ProyectoFinal_GrupoXX_EntregaX - Brief ejecutivo

## 1. Nombre del sistema

**EasyLearn Design System**

EasyLearn es una plataforma academica tipo LMS con enfoque en experiencia de usuario, gestion por roles y sistema visual reutilizable.

## 2. Problema que resuelve

En contextos universitarios, estudiantes, docentes y administradores suelen manejar informacion dispersa: cursos, entregas, fechas, apuntes, usuarios, matriculas y periodos. Esta dispersion genera perdida de tiempo, dificultad para priorizar tareas y sobrecarga cognitiva.

EasyLearn resuelve este problema mediante una experiencia centralizada y organizada por rol:

- El estudiante ve cursos, actividades, calendario y material de estudio.
- El docente ve cursos asignados, estudiantes y entregas pendientes.
- El administrador gestiona usuarios, carreras, periodos, cursos ofertados y matriculas.

## 3. Publico objetivo

### Usuarios principales

- **Estudiantes universitarios:** necesitan encontrar cursos, tareas, fechas y recursos de estudio.
- **Docentes:** necesitan seguimiento de cursos, estudiantes y entregas.
- **Administradores academicos:** necesitan gestionar la estructura institucional del periodo academico.

### Contexto de uso

- Instituciones de educacion superior.
- Programas academicos con multiples cursos y grupos.
- Entornos donde se requiere una plataforma clara, escalable y accesible.

## 4. Propuesta de valor

EasyLearn ofrece una experiencia academica integral basada en tres pilares:

1. **Claridad:** dashboards con informacion prioritaria y acciones visibles.
2. **Consistencia:** sistema de diseno con componentes reutilizables, paleta semantica y navegacion uniforme.
3. **Escalabilidad:** arquitectura Django con modelos para usuarios, roles, cursos, periodos, matriculas, apuntes, glosario y objetivos de repaso.

## 5. Ventajas competitivas

- **Diseño centrado en roles:** cada usuario ve lo que necesita segun su responsabilidad.
- **Sistema visual documentado:** colores, botones, estados, tarjetas y tablas con reglas claras.
- **Accesibilidad desde la base:** labels, ARIA, foco visible, contraste y reduccion de movimiento.
- **Integracion academica:** no solo muestra cursos personales, tambien modela programas, periodos y matriculas.
- **Feedback visual:** estados como activo, pendiente, atrasado, completado y error se diferencian por color y texto.
- **Interfaz moderna y profesional:** uso de Inter, sidebar, cards, tablas y dashboards similares a productos reales.

## 6. Posibles aplicaciones

- LMS institucional para universidades o colegios.
- Portal de seguimiento academico por carrera y periodo.
- Sistema de apoyo a docentes para revisar entregas y estudiantes.
- Plataforma de organizacion personal de apuntes y glosario.
- Base para un sistema de analitica academica o alertas tempranas.

EasyLearn no es solo una interfaz bonita: es una propuesta funcional de sistema academico que reduce friccion, organiza informacion por rol y aplica principios de Interaccion Hombre Computador para mejorar la experiencia educativa.
