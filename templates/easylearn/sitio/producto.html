Our Popular Courses

Sistema de gestión del aprendizaje (LMS) para instituciones de educación superior. Conecta configuración institucional, aula docente y experiencia del estudiante.

Funcionalidades principales

  • Panel estudiante: tablero, calificaciones, calendario y avisos.
  • Aula virtual: cursos, semanas, materiales y entregas.
  • Panel docente: entregas pendientes, calificación y foros.
  • Panel administrador: carreras, períodos, ofertas y matrículas.
  • Notificaciones en tiempo real y perfil académico.
  • Módulo Repaso para apuntes personales del estudiante.

Tecnología utilizada

Stack moderno, mantenible y escalable para entornos educativos.

Python 3 Django PostgreSQL / SQLite HTML5 + CSS3 JavaScript WhiteNoise Pillow
